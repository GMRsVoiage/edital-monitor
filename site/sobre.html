Sobre

Um índice independente de publicações oficiais

O Edital Monitor é um projeto open source criado para facilitar pesquisas em Boletins Oficiais.

Os PDFs permanecem na fonte oficial. O projeto guarda metadados e texto extraído para indicar data, página e link original.

Limitações

Documentos digitalizados, imagens, tabelas e PDFs problemáticos podem gerar resultados incompletos. Sempre confirme no documento oficial.
