Como o projeto trata dados

O buscador indexa conteúdo de publicações oficiais disponibilizadas publicamente pela fonte indicada.

Não é necessário criar conta. Para limitar abuso, a API gera um identificador temporário derivado do IP, da data e de um segredo do servidor. O IP original não é salvo pelo aplicativo na tabela de limite diário.

Evite pesquisar informações que você considere sigilosas. Sempre confirme resultados no documento oficial.
