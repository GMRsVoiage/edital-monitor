# Contribuindo

Contribuições são bem-vindas.

1. Faça um fork.
2. Crie uma branch.
3. Faça alterações focadas.
4. Nunca inclua credenciais, tokens, PDFs ou dados privados.
5. Abra um pull request explicando a alteração.

Mudanças em `.github/workflows/`, `worker/` e rotas `/admin/*` precisam de revisão adicional.

Nunca envie valores reais de `INGEST_TOKEN`, `RATE_LIMIT_SALT`, tokens Cloudflare, GitHub tokens, cookies ou chaves privadas.
